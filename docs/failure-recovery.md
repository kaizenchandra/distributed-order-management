# Failure analysis

Controls describe current implementation unless explicitly marked external/unimplemented. Tests named “pending” are not
execution claims. For all rows, detection uses secured service logs, Saga inspection, participant state and
outbox/consumer lag; financial effects must be reconciled before changing operation identity. User-visible behavior is
pending until terminal confirmation/cancellation or operator resolution.
